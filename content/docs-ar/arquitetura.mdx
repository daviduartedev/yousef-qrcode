## المكوّنات

| الطبقة | التقنية | الغرض |
|---|---|---|
| الويب وHTTP | Next.js App Router وReact وTypeScript | الصفحات العامة والخاصة ومسارات API. |
| الواجهة | Tailwind CSS وRadix UI وLucide | تصميم متجاوب وعناصر تحكم وأيقونات. |
| اللغات | i18next وreact-i18next | الإنجليزية والعربية مع اتجاه RTL. |
| قاعدة البيانات | PostgreSQL على Neon وpg وDrizzle ORM | البيانات العلائقية والمعاملات وترحيلات المخطط. |
| الجلسات | Better Auth | التسجيل وتسجيل الدخول والتحقق من الجلسة على الخادم. |
| التحقق | Zod | التحقق من المدخلات قبل تنفيذ عمليات الخادم. |
| الرموز والتحليلات | qrcode-generator وqr-code-styling وjsQR وRecharts | الترميز والعرض والقراءة من الصور والرسوم البيانية. |
| التوثيق | Fumadocs Core وMDX | محتوى مُدار بالإصدارات وفهارس للمقالات وبحث. |
| الاستضافة والاختبار | Vercel وGitHub Actions وDocker | نشر البيئة التجريبية والفحوص المستمرة وقواعد بيانات اختبار مؤقتة. |

## مسار الطلب والبيانات

1. ترسل الواجهة الطلب إلى Next.js.
2. يتحقق المسار من المدخلات ويحدد الجلسة أو مفتاح API. يحدد الخادم مساحة العمل والصلاحية.
3. تنفّذ طبقة البيانات العملية في PostgreSQL وتعيد الحقول المطلوبة.
4. تتبع مسارات القراءة والإرسال العامة قواعد خاصة. النشر عملية مستقلة عن حفظ المسودة.

## الأمان والتشغيل

تبقى صلاحيات قاعدة البيانات وبيانات اعتماد المزوّدين على الخادم. تقتصر الاستعلامات الخاصة على مساحة العمل المصرّح بها، ويستخدم مخطط قاعدة البيانات أمان مستوى الصفوف كحماية إضافية. تُخزّن تجزئات مفاتيح API وتُشفّر بيانات اعتماد الموصلات وأسرار Webhook. يتحقق النظام من وجهات Webhook للحد من الوصول إلى الشبكات الخاصة.

تفحص عملية التكامل بيانات الاعتماد والأنواع وجودة الشفرة والبناء واختبارات الوحدات وسلوك HTTP. تُسجّل اختبارات المتصفح والترحيل عند انطباقها. تستخدم البيئة التجريبية Vercel وNeon. راجع [حالة التسليم](/docs/ar/status) لمعرفة القرارات المتبقية للإنتاج.
