## واجهة API العامة

في [واجهة API وإشعارات Webhook](/settings/developers)، يمكن لمسؤول مساحة العمل إنشاء مفاتيح API وإلغاؤها. احفظ المفتاح الجديد في مدير الأسرار، إذ يعرضه التطبيق عند إنشائه فقط. أرسله في الترويسة `Authorization: Bearer <KEY>`.

| المسار | الغرض |
|---|---|
| `GET /api/v1/qr-codes` | عرض قائمة الرموز. |
| `POST /api/v1/qr-codes` | إنشاء رمز. |
| `GET /api/v1/qr-codes/{id}` | قراءة رمز من مساحة العمل. |
| `PATCH /api/v1/qr-codes/{id}` | تحديث الحقول المدعومة. |
| `DELETE /api/v1/qr-codes/{id}` | حذف سجل رمز. |
| `GET /api/v1/analytics?from=YYYY-MM-DD&to=YYYY-MM-DD` | قراءة تحليلات فترة. |

تشمل الصلاحيات `qr:read` و`qr:write` و`analytics:read`. يسمح النظام بـ60 طلبًا في الدقيقة لكل مفتاح. راعِ `Retry-After` بعد `429`، وتعامل مع `401` و`403` و`404` وفق المفتاح والصلاحية والمورد.

## إشعارات Webhook الموقّعة

أعدّ نقطة استقبال عامة عبر HTTPS واختر `qr.scanned` أو `form.submitted` أو `card.contact`. تحقّق من توقيع HMAC-SHA256 للطابع الزمني ونص الطلب الخام قبل المعالجة. استخدم `QRConnect-Event-Id` لمنع التكرار وارفض الطلبات خارج النافذة الزمنية المسموح بها. تتيح اللوحة الاختبار والإيقاف المؤقت وإعادة الإرسال وسجل التسليم. تعتمد إعادة المحاولة المجدولة على إعداد الاستضافة.

## الموصلات

تدعم [التكاملات](/integrations) خدمات Slack وHubSpot وGA4. يرسل Slack الأحداث المختارة. ينشئ HubSpot سجلات من بيانات الاتصال التي تمت مشاركتها بموافقة صاحبها ويترك السجلات الموجودة كما هي. يستقبل GA4 أحداث المسح. يمكن ربط Zapier وMake وn8n بواسطة Webhook.

اختُبرت الموصلات باستخدام نقاط استقبال محلية. راجع [حالة التسليم](/docs/ar/status) لمعرفة وضع التحقق باستخدام حسابات اختبار لدى المزودين.
