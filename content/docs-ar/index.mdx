## ابدأ بما تريد إنجازه

- **إنشاء رمز QR ومشاركته.** اختر المحتوى وخصّص التصميم ونزّل صورة للطباعة أو المشاركة. [دليل رموز QR](/docs/ar/qr-codes)
- **قياس الأداء.** راجع عمليات المسح حسب الرمز والفترة والجهاز والبلد عند توفر البيانات. [التحليلات](/docs/ar/analytics)
- **نشر المحتوى.** أنشئ صفحة روابط أو بطاقة أعمال رقمية أو نموذجًا وشارك عنوانه. [صفحات الروابط والبطاقات والنماذج](/docs/ar/paginas-e-cartoes)
- **العمل مع فريقك.** بدّل بين مساحات العمل وأدر الصلاحيات وأعد استخدام الملفات. [مساحات العمل والملفات](/docs/ar/espacos-e-arquivos)
- **ربط أدوات أخرى.** استخدم مفاتيح API محددة الصلاحيات أو إشعارات Webhook موقّعة أو أحد الموصلات المدعومة. [واجهة API والتكاملات](/docs/ar/api-e-integracoes)

## الدخول إلى المنتج

[سجّل الدخول إلى QRConnect](/auth). يدعم المنتج الإنجليزية والعربية، وتُعرض الواجهة العربية من اليمين إلى اليسار.

تعرّف على التقنيات في [البنية التقنية](/docs/ar/arquitetura)، وعلى الميزات التي جرى التحقق منها والفروق مع Uniqode والعمل المتبقي في [حالة التسليم](/docs/ar/status).
