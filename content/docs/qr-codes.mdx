## Create a QR code

Choose **Create New**, select a type, enter its content, customize the design, and review the final screen. Available types include Website, text, email, phone, SMS, Wi-Fi, and QR codes linked to published Linkpages, cards, forms, or supported media.

- **Direct.** The file embeds its content or destination. Later changes require replacing the distributed file.
- **Tracked.** The code uses a redirect address. For a tracked Website code, change the destination while keeping its public QR address. The details view shows its history.

## Customize and download

Apply templates, colors, logos, patterns, eye styles, and frames. Reopen the saved design from the list. Export PNG or SVG, choose a size and error correction level where available, and scan the file with a phone before distributing it.

## Organize and work in bulk

In [My QR Codes](/my-qrcodes), switch between list and grid. The URL preserves search, filters, sorting, and pagination. Use field operators, folders, labels, watchlist, and lifecycle filters. Global text search supports keyboard access, and image search can find an existing QR code in the workspace.

Select records to apply labels or download PNG or SVG files in a ZIP. **Import CSV** previews a UTF-8 file of up to 50 Website QR codes and 128 KiB. Use the columns `title,destination_url` and optional `mode` (`direct` or `tracked`). The report identifies records created, skipped, or failed.

## Control redirects

Pause a tracked QR code to suspend its redirect and reactivate it at the same address. Review the effects of deletion before confirming. Compatible QR codes can use aliases, passwords, schedules with a time zone, or consent-based location. Real domain and TLS verification are tracked in [Delivery status](/docs/status).
